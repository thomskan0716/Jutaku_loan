===============================================
TROUBLESHOOTING
===============================================

Error: Could not find or load main class migration.MigrationBatchApplication
  → Build project first (NetBeans or compile_for_vm.bat)
  → Check bin\main folder has .class files

Error: Package org.springframework does not exist
  → Add libs\*.jar to NetBeans Libraries
  → Verify libs folder has Spring Boot JARs

Error: ORA-01017 Invalid username/password
  → Edit application.yml with correct passwords
  → Verify database connection with SQL*Plus first

Error: No database connection
  → Check TNS configuration
  → Verify Oracle listener is running
  → Test: tnsping E00197SV0203

Error: Batch script hangs
  → Check database locks
  → Verify FOR UPDATE SKIP LOCKED is working
  → Check application logs

===============================================
PERFORMANCE TUNING
===============================================

JVM Memory:
  -Xms512m  (initial heap)
  -Xmx2048m (maximum heap)
  
  For larger datasets, increase in run.bat:
  -Xmx4096m or -Xmx8192m

Parallel Instances:
  Default: 15 instances
  Adjust in create_batches.bat:
    for /L %%i in (1,1,15) do (
    Change 15 to desired number (10-20 recommended)

Database Connection Pool:
  Edit application.yml:
    hikari:
      maximum-pool-size: 10

Batch Size:
  Default: 100 records per range
  Adjust in ApplicationMigrationService.java:
    BATCH_SIZE = 100
